按支架查页：行首勾选 + 批量删除 v1.0

2026-10-28 · 副作用范围：该页表格（按车型查页不动）· 状态：待确认，未写代码

1 需求

用户原话：「把这个删除按钮放在列表的上方，给列表每一行加个 checkbox，这样可以多选，做批量删除」。

项目结论说明
行内「删除」移除操作列只留「编辑」，96px → 60px
删除入口上移到工具条表格上方新增 32px 工具条：「全选」勾选框 + 「删除选中（N）」按钮 + 右侧计数
行首 checkbox新增一列宽 36px，36×36 可点区域；点勾选不改变行高亮（两者互不干扰）
批量删除一次事务只备份一次、单事务删完；部分 id 已不存在时按实际删除数回报
行内「编辑」保留改品牌/车型/年款仍用弹窗（重命名操作，不适合批量）

2.2 勾选列的行为

操作结果
点行首方框勾选/取消该行；行高亮（selection）不变，仍可用「编辑」
点行内其它位置只改变高亮，不改变勾选
点「全选」勾选当前查询结果的全部行（受品牌筛选影响，不是全库）
已全部勾选时点「全选」取消全部（变为半选/空选）
切换支架号 / 改品牌筛选 / 重新查询勾选清空（避免删到看不见的行）
删除成功后勾选清空、列表重查、计数归零

5 规范

项目值约束
工具条高度32 px底边 1px 分隔线；与表格之间无额外间距
工具条元素全选 · 删除选中（N）· 计数计数右对齐，文案「共 N 条 · 已选 M」
勾选列宽36 px固定在首列；表头显示 ☐，可点=全选
勾选框13 × 13，圆角 3未选：透明底 + 边线；已选：强调色实心；半选：半填充
行高38 px（不变）勾选框垂直居中，不撑高行
操作列96 → 60 px只剩「编辑」，表格让出 36px 给勾选列
按钮态danger / danger-off0 条=禁用灰；≥1 条=红边红字；文案带数量
刷新策略查询变化即清空勾选不做「跨查询保留选择」，避免删到看不见的行

6 数据与接口

app/db.py  新增 Repository.delete_fitments(row_ids) -> dict
    备份一次（backup_database）
    单事务：DELETE FROM fitments WHERE id IN (?…)
    返回 {"deleted": n, "missing": m, "backup": path}
      missing = 请求里已经不存在（被别处删掉）的条数，不算失败
    被爬虫锁库时沿用 _write_error -> "数据库正被别的程序占用…"
    旧的 delete_fitment(id) 保留（行内删除已移除，但测试脚本还在用）

app/models.py  DictTableModel 增加勾选列支持（通用，不只这一页）
    列键 "__check__" = 勾选列
    data(CheckStateRole) / setData(CheckStateRole) / flags(ItemIsUserCheckable)
    checked_ids() / checked_count() / check_all(list_of_ids) / clear_checked()
    set_rows() 时自动丢弃已不存在的 id（换支架号不会残留选择）

app/pages/bracket_page.py
    COLUMNS 首列插 ("__check__", "", 36)，操作列 96 -> 60
    chips 2 -> 3，dots 4 -> 5（列索引整体右移一位）
    表格上方插工具条（全选 QCheckBox + 删除选中 QPushButton#danger + 计数 QLabel）
    run_query() 末尾清空勾选并刷新计数
    Delete 键：有勾选 -> 删勾选；无勾选 -> 删当前行（保留旧习惯）
    LinkDelegate 由 ("编辑","删除") 改为 ("编辑",)

app/theme.py   补 QCheckBox / QTableView::indicator 的方框样式（当前 QSS 没有，
    深色主题下默认指示器几乎看不见）
为什么批量删除要新写方法：现在 delete_fitment() 每条都 backup_database() 一次并单独开事务。删 14 条 = 14 份快照（ data/backup/ 只留 10 份，会把更早的备份挤掉），且中途失败只删了一半。 批量版只备份一次、一个事务全成或全不成。

7 对照与备选

能力现状改后
删除入口每行操作列「删除」工具条「删除选中（N）」
多选无（单选行高亮）行首 checkbox + 全选
连删 14 条14 次点击 + 14 次确认 + 14 份快照2 次点击 + 1 次确认 + 1 份快照
行内编辑「编辑 / 删除」只剩「编辑」（不变）
按车型查页独立表格，同样「编辑 / 删除」本次不动（可作为下一步统一）

未采用 / 待你拍板

  • 表格表头自带勾选框（点表头全选）：Qt 支持，但点击热区小、样式难控， 不如工具条「全选」稳（未采用）。
  • 整列去掉操作、改双击行编辑：双击与勾选框点击容易误触（未采用）。
  • Delete 键删勾选、无勾选时删当前行：保留旧习惯，但威力变大 —— 若你希望「Delete 键只删勾选、绝不删当前行」，告诉我改成后者。
  • 跨查询保留勾选：可能导致「删掉当前看不见的行」，不做。
